# Security policy

## Supported versions

Security fixes are made against the latest version on the `main` branch. When
published releases are available, the latest release is the supported version.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions.
Use GitHub's private **Report a vulnerability** feature:
<https://github.com/Davin-X/mac-terminal/security/advisories/new>.

Include the affected version, macOS version, steps to reproduce, and impact.
Do not include real credentials, private keys, or sensitive terminal output.
Please allow time for an acknowledgement and coordinated fix before public
disclosure.

Mac Terminal runs commands with the permissions of the logged-in user. Do not
run commands you do not trust.
